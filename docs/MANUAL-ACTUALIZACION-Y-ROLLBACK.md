# Actualización y rollback

Desde **Configuración avanzada → Actualizaciones**, seleccioná el ZIP oficial. Antes de modificar código o tablas se crea un respaldo automático. Para bajar de versión elegí rollback y escribí `ROLLBACK`. Configuración, credenciales, uploads y almacenamiento están protegidos. Un ZIP instalable o un respaldo portable no se aceptan como actualización.

Para pasar de 2.0.2 a 2.1.0 utilizá `AranduGo-2.1.0-update-from-2.0.2.zip`. Para volver al código 2.0.2 utilizá el paquete de rollback específico; el panel creará antes otro respaldo completo.
