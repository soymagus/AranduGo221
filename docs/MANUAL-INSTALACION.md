# Instalación de Arandu Go 2.1.1

1. Subí y extraé el contenido del ZIP en la raíz o en una subcarpeta propia.
2. Abrí esa URL. El sistema redirigirá a `install/`.
3. Confirmá los requisitos, la URL detectada y la zona horaria.
4. Usá una base independiente o un prefijo exclusivo. El instalador bloquea prefijos ocupados.
5. Elegí **contenido de ejemplo** o **sitio vacío** y creá el administrador.
6. Al finalizar, ingresá al dashboard. El instalador quedará bloqueado.

Cada copia debe tener su propia carpeta, configuración, almacenamiento y prefijo. No uses enlaces simbólicos para compartir `uploads`, `storage` o configuración entre instalaciones.
