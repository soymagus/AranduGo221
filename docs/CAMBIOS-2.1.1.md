# Arandu Go 2.1.1

Revisión correctiva de interfaz sobre 2.1.0.

- Accesos directos y filtros reemplazados visualmente por dos selectores compactos.
- Selector Edición completa / Configuración guiada con estilo clásico y reducido.
- Flechas Anterior y Siguiente y botón Salir visibles antes del contenido del paso; los controles inferiores se conservan.
- Galería presentada en una sola columna, con miniatura y todas las fichas cerradas inicialmente.
- Apertura exclusiva: al editar una foto se cierran las demás.
- Carga múltiple de imágenes, respetando el máximo total de 24; cada archivo crea su propia ficha editable.
- Seis contenidos libres presentados como lista cerrada, con apertura exclusiva.

No cambia el esquema de datos de 2.1.0 ni elimina funciones existentes.
